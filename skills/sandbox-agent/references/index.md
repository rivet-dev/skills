# Sandbox Agent

> Source: `sandbox-agent/docs/content/docs/index.mdx`
> Canonical URL: https://rivet.dev/sandbox-agent/docs/index
> Description: Run coding agents in sandboxes. Control them over HTTP.

---
Sandbox Agent runs inside your sandbox and gives your app one API for Claude Code, Codex, OpenCode, Cursor, Amp, and Pi. Stream events, handle permissions, and manage sessions from the TypeScript SDK or HTTP.

- [Quickstart](/sandbox-agent/docs/quickstart) — Install Sandbox Agent and send your first message.

- [SDK Overview](/sandbox-agent/docs/sdk-overview) — Control agents from your application.

- [Deploy](/sandbox-agent/docs/deploy/local) — Run locally or inside your sandbox provider.

- [HTTP API](/sandbox-agent/docs/api-reference) — Explore endpoints, request bodies, and responses.
