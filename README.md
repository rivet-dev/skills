# Rivet Skills

The top-level `rivet-*` skills and their embedded examples are generated by
[rivet-dev/website](https://github.com/rivet-dev/website)
(`.github/workflows/skills.yml`). Only those directories are replaced on
each website publish.

`skills/sandbox-agent` is generated and published independently by
[rivet-dev/agents](https://github.com/rivet-dev/agents)
(`.github/workflows/skill-generator.yml`).

To change a generated skill, edit its source documentation in the owning
repository. Other publishers' directories are preserved.
